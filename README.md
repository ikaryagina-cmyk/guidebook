# Гайдбук франчайзи «Квиз, плиз!»

Сайт с гайдами для городов-франчайзи. Страница статическая (GitHub Pages), гайды и доступы хранятся в Supabase и в репозиторий не попадают.

- `index.html` — сайт; собирается из исходника командой `python3 tools/build.py <исходник> index.html`
- `sb.js` — подключение к Supabase: вход, чтение и запись гайдов, картинки
- `config.js` — адрес проекта Supabase и публичный ключ
- `supabase/setup.sql` — таблицы и правила доступа, запускается в SQL Editor

Сотрудники городов входят по почте из списка доступа и видят только свои разделы. Редакторы входят по почте и паролю. Новых редакторов добавляют на сайте в разделе Отдел → Редакторы: сайт выдаёт код приглашения, и коллега сам создаёт пароль. Для этого в Supabase должны быть включены Allow new users to sign up и выключено Confirm email.
